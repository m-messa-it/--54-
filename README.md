ПР-54 Збереження даних у бінарних форматах

## Контрольні запитання

### 1. Чим відрізняється запис числа 10 у текстовий файл від запису цього ж числа типу int у бінарний файл? Скільки байтів займає кожен запис?

У текстовому файлі число перетворюється на рядок із символів '1' та '0', кожен символ записується за своїм кодом (0x31 та 0x30), тому такий запис займає 2 байти. У бінарному файлі записується саме значення типу int у вигляді 4 байтів пам'яті (0x0A 0x00 0x00 0x00), незалежно від кількості цифр у числі.

### 2. Від чого залежить кількість байтів, яку займає значення в бінарному файлі?

Кількість байтів у бінарному файлі залежить виключно від типу даних, а не від самого значення. Наприклад, значення типу byte завжди займає 1 байт, short — 2 байти, int — 4 байти, double чи long — 8 байтів.

### 3. Чому при відкритті бінарного файла в текстовому редакторі частину даних не видно, а інша частина виглядає як незрозумілі символи?

Текстовий редактор намагається інтерпретувати кожен байт як код символу. Байти з числовими значеннями керівних символів (наприклад, 0x00 — NUL, 0x0A — новий рядок) не відображаються або виглядають як порожнє місце. Байти, які випадково збігаються з кодами друкованих символів, показуються як літери, а інші перетворюються на незрозумілі знаки або символ заміни. Бінарний файл призначений для читання програмою за правилами формату, а не для редактора.
